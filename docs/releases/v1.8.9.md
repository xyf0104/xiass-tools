# XIASS Tools v1.8.9

## Codex API Key 登录修复

- 修复应用 API Key 配置后，Codex 新进程无法读取认证、要求重新登录的问题。
- 认证写入采用 `auth_mode: "apikey"` 与 `OPENAI_API_KEY`，清除旧版本误写入的 `experimental_bearer_token`；仍兼容读取旧字段以迁移配置。
- 加强写后校验：除文件内容一致外，验证 API Key 认证所需的字段，拒绝只有旧 bearer 字段的认证文件。
- 显式 API Key 模式缺少有效 `OPENAI_API_KEY` 时，不再报告认证缓存可用。
- 保留已有 OAuth tokens 的切回能力；API Key 模式下的用量查询不会误用残留 OAuth tokens。

## 在线更新

- 保留应用内 GitHub 最新版检查、下载安装包、下载进度和 SHA-256 校验。
- 合并 v1.8.8 的回退改进：GitHub API 不可用时，从公开 Release 页面获取安装包及 GitHub 提供的 SHA-256，不降低校验要求。

## 安装包

仅提供以下三个安装包：

- `XIASS.Tools_1.8.9_aarch64.dmg`：macOS Apple Silicon（M 系列芯片）。
- `XIASS.Tools_1.8.9_x64.dmg`：macOS Intel。
- `XIASS.Tools_1.8.9_x64-setup.exe`：Windows x64。

## 升级后使用

1. 安装 v1.8.9，并确认 XIASS Tools 显示的版本号已更新。
2. 在 Codex 配置页重新应用已保存的 API Key 配置，使认证文件按新格式写入。如果该配置已处于激活状态、无法再次应用，先切换到另一配置，再重新应用目标配置。
3. 保存工作后，重新启动 Codex，使新进程读取配置和认证文件。

安装升级本身不会主动替换你当前的 Codex 登录凭据；认证写入发生在配置应用操作中。认证格式兼容性测试不代表上游 API Key 有效性或额度验证。
