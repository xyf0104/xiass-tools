# XIASS Tools v1.9.11

## Codex model directory completion

- Added `gpt-6-sol` and `gpt-6-luna` to the shared Codex model directory for macOS and Windows.
- Codex setup and profile editing now show the XIASS built-in model list while preserving models returned by a configured API endpoint.
- Official OAuth, JSON-account, and API-key Codex flows can select the same built-in model list.
- Newly written Codex custom Provider entries include the XIASS model directory in `config.toml`.
- Codex desktop enhancement injection and the Windows/WF Bridge inspection path merge the same model fallback without replacing the user's existing catalog.
- Added regression coverage for model catalog fallback, Provider model-directory writes, and cross-platform inspection output.

This release does not include API keys, OAuth tokens, account JSON, or local credential data.
