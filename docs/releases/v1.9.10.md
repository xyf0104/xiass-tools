# XIASS Tools v1.9.10

## Cockpit Codex 账号池导入修复

- 按 Cockpit 原生账户池格式处理 `accounts[].credentials`，支持 `access_token`、`refresh_token`、`chatgpt_account_id` 及常见字段别名。
- 合法的 Cockpit OAuth 账号可以没有 `id_token`；只要存在 `access_token` 即可导入，存在 `refresh_token` 时可在 Codex 启动后刷新。
- 导入后只生成 Codex 原生 `auth_mode=chatgpt` 结构，不伪造空的 `id_token`，并在写入前后保持本机凭据隔离。
- 修正导入错误提示和输入说明，明确 `id_token` 对 Cockpit 账号不是必填项。
- 已使用用户提供的 Cockpit 账户池 JSON 做本地回归验证；发布内容不包含任何真实 Token、API Key 或账户数据。
