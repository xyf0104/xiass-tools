# XIASS Tools v1.9.8

## Codex JSON 账号导入修复

- 兼容 Cockpit 等工具导出的 `tokens: [{ ... }]` 数组结构，能够正确识别其中的 `access_token`、`id_token`、`refresh_token` 和账号标识。
- 继续只遍历受支持的凭据容器和对象成员，并保留账户数量、JSON 大小和遍历深度限制；凭据不会进入日志、浏览器存储或 GitHub。
- JSON 账号导入模式不再显示配置名称、模型和审查模型，只保留账号导入与 Codex 上下文能力设置。
- 账号导入模块现在位于上下文窗口和 model capabilities 模块上方，缩短导入流程并避免无关字段干扰。
