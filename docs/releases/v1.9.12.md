# XIASS Tools v1.9.12

## Codex model catalog and model fetching

- Writes a real `model_catalog_json` file that Codex loads at startup.
- Preserves existing user catalog entries and metadata instead of overwriting the original catalog.
- Adds `gpt-6-sol` and `gpt-6-luna` to the local Codex catalog when a XIASS Codex profile is applied.
- Verifies the catalog file and the `config.toml` pointer after writing.
- Applies the same catalog logic through the macOS and Windows paths.
- Keeps API model fetching authoritative: only unique IDs returned by the configured backend are shown.
- Clears stale model results when the endpoint, protocol, or API key changes, and ignores late responses from old requests.

## Verification

- Codex `model/list` was tested in an isolated `CODEX_HOME`; both `gpt-6-sol` and `gpt-6-luna` were returned.
- Frontend, Rust, and WF bridge test suites pass.
