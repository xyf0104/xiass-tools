# XIASS Tools v1.9.13

## Antigravity model refresh and GPT-6 model injection

- Keeps enabled Antigravity models, including `gpt-6-sol` and `gpt-6-luna`, in the local model catalog used by the WF bridge.
- Verifies that enabled custom models are written into both the Antigravity model container and its picker index.
- Adds a regression test covering `gpt-6-sol` and `gpt-6-luna`, while ensuring explicitly disabled models remain excluded.
- Makes the save and delete confirmations explicit: Antigravity must be restarted to refresh its cached model list.
- Preserves the existing fail-closed behavior when Antigravity returns an unsupported or incomplete model-list schema.

## Verification

- WF bridge full Go test suite passes with `go test -tags wfbridge ./...`.
- Local storage inspection confirmed both GPT-6 models are enabled in `custom_models.json`.
- The remaining local refresh failure was traced to Antigravity's upstream OAuth token request timing out before `fetchAvailableModels`; this release makes the required restart step explicit and adds coverage for the injection path.
