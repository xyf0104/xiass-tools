# XIASS Tools v1.9.9

## Cockpit Codex 账号池 JSON 兼容修复

- 兼容 Cockpit 原生账户池导出格式：`accounts[].credentials.access_token`、`refresh_token`、`chatgpt_account_id` 等字段。
- 支持只有 `access_token + refresh_token`、没有 `id_token` 的合法 OAuth 账户；不会再把 `id_token` 错误地当成必填字段。
- 导入后只写入实际存在的凭据字段，不会伪造空的 `id_token`。
- 重启后 Codex 状态识别同样接受 access token 搭配 refresh token 的原生账户格式。
- 已用真实 Cockpit 账户池 JSON 做脱敏回归验证；Token 不会输出到日志、前端响应或发布内容。
