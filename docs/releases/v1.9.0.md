# XIASS Tools v1.9.0

发布日期：2026-09-09

## 主要更新

- ChatGPT 桌面端改为“选择 Codex 配置 → 启动 → 辅助功能”的两步流程。
- 新增配置入口直接进入 Codex 配置向导，并预填 XIASS API 默认项。
- 启动前写入并校验所选 Codex 配置；配置写入失败时不会启动客户端。
- 已运行的 ChatGPT 桌面端会在切换配置后重新启动，确保读取最新配置。
- Codex 自定义 Provider 显示名称与配置名称统一，支持空格和中文。
- 2FA 管理支持保存前自定义名称、保存后行内重命名，并缩小查询与保存卡片。
- 修复 macOS Dock 点击后无法恢复主窗口的问题。
- 保留 ChatGPT Desktop 原有安装、更新、卸载、插件增强、模型白名单、Fast 和能力检查功能，并归入辅助功能。

- macOS x64 DMG
