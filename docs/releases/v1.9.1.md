# XIASS Tools v1.9.1

发布日期：2026-09-09

## 主要更新

- 收紧 ChatGPT 桌面端选择配置与启动页面的字号、卡片高度和间距，统一到接入配置页面的紧凑视觉密度。
- 将配置详情改为紧凑的名称、Base URL、模型摘要；宽窗口横向排列，窄窗口自动换行。
- 下一步、保存、启动等主操作使用略大的 18px 图标，普通操作保持 16px，仍使用橙色流光渐变按钮背景。
- 步骤切换后自动把键盘焦点移动到新页面标题；配置写入或启动期间锁定步骤切换，避免中断流程。
- 新建配置入口在无配置时仍可用；返回、选择、写入校验和启动流程保留原有配置选择。
- 项目仓库、在线更新、下载和 WF Bridge 的 GitHub 标识统一迁移到 `xyf0104/xiass-tools`。
- 保留旧 Antigravity WF 备份目录与旧助手 Bundle ID 的只读兼容识别，不影响已有本地数据迁移。
