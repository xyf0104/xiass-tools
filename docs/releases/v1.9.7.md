# XIASS Tools v1.9.7

## Windows Codex API Key 导入修复

- 统一规范化 API Key 的保存、读取、模型列表请求和 Codex `auth.json` 写入链路。
- 兼容从 JSON、`.env`、旧版配置复制来的 `Bearer ...`、`OPENAI_API_KEY=...`、外层引号和 UTF-8 BOM 包装。
- Windows 启动 Codex 前只清理 XIASS Tools 当前进程中的 `OPENAI_*` 覆盖变量，避免旧环境变量覆盖刚写入的 `auth.json`；不会修改系统或用户环境变量。
- 保持 `https://api.xiass.com/v1/responses` 的 Responses API 链路不变。
